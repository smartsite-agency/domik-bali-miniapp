# Домик на Бали — Telegram Mini App

Гайд по будівництву дому 7 × 4 м (28 м²) на Балі (участок Олі). Фасад: у вітальні й спальні — розсувні вікна від підлоги до стелі, глуха стіна тільки в санвузла (душ і туалет). Застосунок показує історію в 8 екранах і веде користувача до Telegram-каналу стройки.

## Структура

Статика без збірки й залежностей.

- `index.html` — усі екрани. Кожен екран: `<section class="screen" data-label="…" data-cta="…">`.
  - `data-label` — назва кроку у шапці.
  - `data-cta` — текст нижньої кнопки на цьому екрані.
  - `data-desc` — один рядок опису для панелі «Содержание» (до ~35 символів, інакше обріжеться на 360px).
- `app.js` — логіка:
  - `render()` показує поточний екран, оновлює прогрес і текст кнопки.
  - `go(i)` / `next()` — навігація; свайп > 60 px і стрілки клавіатури.
  - У Telegram: `MainButton` і `BackButton` замість власних кнопок, тема з `tg.colorScheme`, haptic.
  - Екран 2 «До стройки» — три некликабельні картки (`.cards`/`.card`) з рядком-замком «Как мы это решили — в гайде» (`.card-lock`), без логіки в JS.
  - `CHANNEL_URL` — посилання на канал стройки (поки порожнє → показується `#linkNote`).
  - Навігація: сегменти прогресу — кнопки на екран; «☰ Содержание» відкриває bottom sheet (`openToc`/`closeToc`). Поки панель відкрита (`tocOpen`), свайп і стрілки вимкнені, Telegram BackButton закриває панель. Усі переходи — через `go(i)`.
- `style.css` — кольори як змінні на `:root` (світла + темна тема), шрифти Roboto Slab 700 (`--display`: заголовки, великі цифри, кнопка) і Literata 300/400/600 (`--body`: 300 тільки для `.lead`, дрібний текст ≥ 400; шрифт обов'язково з кирилицею), ширина до 560 px. Компоненти: `.facts`, `.specs`, `.cards`, `.rules`, `.big`, `.steps`, `.seg`, `.chapters`, `.note`, калькулятор — `.calc-*`, `.stepper`, `.switch`.
- `img/` — hero, plan, facades, fasten, r1–r3 (рендери альтернативної моделі).
- `calc-data.js` — ціни калькулятора (`CALC_DATA`): min/max у рупіях, курс `USD_RATE`, дні й ставки спеціалістів, терміни. Цифри приблизні (`// ПРИБЛИЗНО`), міняти тільки тут.
- `calc.js` — логіка екрана «Калькулятор» (`#calc`): стан вибору → `compute()` → `render()` при кожному кліку. Елементи керування в `.noswipe` — на них свайп між екранами вимкнено. Віддає `window.CalcApp` (спільний стан, `compute(over)`, `onRender`) для інших екранів.
- `plan.js` — екран 3 «Какой дом получится» (`#layouts`): SVG-схема планування в масштабі за шириною/довжиною з калькулятора (1 одиниця = 1 см), характеристики, «от Rp X млн · N недель» через `CalcApp.compute`. Вибір планування (`state.layout`: studio / bedroom / loft) спільний з калькулятором.

Порядок екранів: Начало → До стройки → Дом → Каркас → Калькулятор → Сроки → Вариант → Гайд.

Щоб додати екран — новий `<section class="screen">` з `data-label`, `data-cta` і `data-desc`; прогрес, лічильник і «Содержание» будуються самі. Усі переходи йдуть через `go(i)` за індексом екрана — при зміні порядку перевірити, чи немає жорстко прописаних індексів.

## Правила текстів

Тексти в застосунку — російською.

1. **Одна думка на екран.** Якщо на екрані дві теми — ділити на два екрани.
2. **Цифри замість прикметників.** «28 м²», «8 етапів», «4–4,5 т», а не «компактний», «швидко», «легкий».
3. **Кнопка = дієслово + що відкриється.** Текст `data-cta` описує наступний екран: «Смотреть дом», «Сколько стоит». Не «Дальше», не «Ещё».
