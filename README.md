# Домик на Бали — Telegram Mini App

- `index.html` — разметка экранов
- `style.css` — стили и цвета
- `app.js` — логика: свайпы, кнопки Telegram. Ссылку на канал впиши в `CHANNEL_URL`
- `img/` — картинки

Локально: открой `index.html` через Live Server в VS Code.
Публикация: GitHub Pages, ссылку вставить в @BotFather.
